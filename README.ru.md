## Зачем это нужно

У тебя уже есть `~/.ssh/config`. И где-то лежит текстовый файлик с IP-адресами.
unissh заменяет и то, и другое — на то, на что можно просто смотреть.

- **Показывает парк, а не список строк.** Живой статус, пинг, CPU, память, диск и поднятые
  туннели — прямо рядом с сервером, на котором стоит курсор.
- **Настраивает новые машины сам.** Дай ему свежий VPS и root-пароль: создаст sudo-пользователя,
  поставит ключ, захарденит `sshd`, настроит файрвол и fail2ban — *и проверит, что вход по
  ключу работает, прежде чем отключить пароли.*
- **Не разбрасывается паролями.** Никакого `sshpass`. Ничего на диске. Пароли живут в
  системной ключнице — Keychain на macOS, Secret Service на Linux. Буфер обмена сам
  очищается через 45 секунд, а в `argv` попадает только SHA-256 секрета, не он сам.
- **Не мешается.** Всё делается одной клавишей. Мышь тоже работает — если хочется.

## Возможности

### Каждый день

- **Подключение одной клавишей.** `c` на любом сервере. Открывается в новом окне терминала —
  Warp, iTerm2, Terminal.app, kitty, gnome-terminal и другие определяются автоматически —
  или в текущем окне, как захочешь.
- **Авто-вход по паролю.** Для парольных серверов пароль вводится сам, через `expect`.
  Сразу готовая сессия, без плясок с буфером обмена.
- **Папки.** Группируй сервера, сворачивай через `←`/`→`. Клавиша `m` **берёт сервер** —
  и он едет по папкам вместе с курсором, пока не положишь его на `Enter`.
- **Мультивыбор и групповые действия.** `space` отмечает сервер (на строке папки — всю группу).
  Выполнить команду на всех, перенести пачкой, удалить пачкой.
- **Поиск, сортировка, избранное.** `/` — фильтр, `s` — перебор сортировок, `f` — закрепить наверху.

### Управление парком

- **Живой монитор** прямо на главном экране: CPU, RAM, диск, load, скорость сети, аптайм и
  все IP-адреса интерфейсов — по *одному постоянному* SSH-соединению, поэтому fail2ban
  никогда не увидит шторм переподключений.
- **Дашборд здоровья парка.** Одна таблица, все сервера, самые нагруженные — сверху.
  Отвечает на вопрос «кому сейчас плохо» одним нажатием.
- **Проброс портов.** Туннели `-L`, `-R` и `-D` (SOCKS5) работают в фоне, а их состояние
  видно прямо в панели статистики — работает, остановлен или упал *с причиной*.
- **Передача файлов** через `scp`, с прогрессом, в обе стороны.
- **Журнал.** Каждый вход, каждая команда с кодом выхода, каждая передача файла.

### Первоначальная настройка

- **Автонастройка свежего VPS**: обновление системы, базовые пакеты, sudo-пользователь со
  сгенерированным паролем, SSH-ключ, UFW/firewalld, fail2ban, харденинг sshd, смена SSH-порта,
  swap, часовой пояс, hostname, автообновления безопасности.
- **Защита от потери доступа.** Вход по ключу проверяется *до* отключения паролей. Если после
  рестарта `sshd` проверка не прошла — конфиг откатывается через ещё живую root-сессию.
  Полный список инвариантов — в
  [ARCHITECTURE.md](ARCHITECTURE.md#12-bootstrap-инварианты-против-потери-доступа).

### Мелочи, которые делают жизнь

**ssh-agent** и ключи с passphrase · **ProxyJump / бастион** · **сниппеты** частых команд ·
**импорт из `~/.ssh/config`** · **экспорт обратно**, чтобы `ssh <имя>` работал из любого
терминала · **бэкапы конфига с восстановлением** · **пять цветовых тем** ·
**два языка интерфейса**.

## Установка

```bash
# Go (рекомендуется)
go install github.com/MrBenoit/unissh@latest

# Из исходников
git clone https://github.com/MrBenoit/unissh
cd unissh && ./install.sh
```

> Homebrew (`brew install MrBenoit/tap/unissh`) в планах — раскомментируй блок `brews`
> в `.goreleaser.yaml` и добавь токен tap-репозитория.

**Требования.** Go ≥ 1.26 для сборки из исходников. **Поддерживаются и macOS, и Linux.**
**Сервера**, которыми ты управляешь, должны быть на Linux: монитор читает `/proc`,
а bootstrap знает `apt` и `dnf`.

Без необязательных утилит unissh работает — просто с меньшим комфортом:

| Возможность | macOS | Linux |
|---|---|---|
| Хранение паролей | Keychain (встроен) | `secret-tool` — пакет `libsecret-tools`. Иначе файл `0600` |
| Буфер обмена | `pbcopy` (встроен) | `wl-clipboard` на Wayland, `xclip` или `xsel` на X11 |
| Авто-вход по паролю | `expect` (встроен) | `expect` — `apt install expect` |
| Новое окно терминала | Warp / iTerm2 / Terminal.app | kitty, foot, ghostty, wezterm, alacritty, gnome-terminal, konsole, xfce4-terminal, xterm или `$TERMINAL` |

```bash
# Ubuntu / Debian, всё сразу:
sudo apt install expect wl-clipboard libsecret-tools
```

Если эмулятора терминала не нашлось, unissh молча подключится в текущем окне, а не упадёт
с ошибкой. `./install.sh` сам скажет, чего не хватает.

## Использование

```
unissh              интерактивное меню
unissh <имя>        быстрое подключение (по префиксу имени, напр. `unissh prod`)
unissh list         список серверов со статусами (работает и без TTY)
unissh add          добавить сервер
unissh version      версия
```

### Горячие клавиши

Нажми `?` внутри приложения — этот список всегда под рукой.

| Клавиша | Действие |
|---|---|
| `tab` / `shift+tab` | переключить панель |
| `↑` `↓` / `k` `j` / мышь | навигация; `g` / `G` — в начало / в конец |
| `enter` / `→` | действия сервера (или развернуть папку) |
| `space` | отметить сервер — на строке папки отмечает всю группу |
| `c` | подключиться |
| `t` | проброс портов |
| `f` | избранное |
| `s` | сменить сортировку |
| `/` | поиск |
| `n` `r` `d` | создать / переименовать / удалить папку |
| `m` | взять сервер и нести его по папкам |
| `shift`+`↑↓` | порядок папок |
| `?` `esc` `q` | справка · назад · выход |

### Добавление сервера с автонастройкой

1. `unissh` → **Добавить сервер**
2. Имя, IP, порт → **С первоначальной настройкой**
3. Введи root-пароль (тот, что прислал хостер)
4. Отметь нужные шаги — всё безопасное включено по умолчанию
5. Иди за кофе. Вернёшься к карточке с новым логином и сгенерированным паролем —
   он уже в Keychain и в буфере обмена.

> ⚠️ После харденинга вход по паролю **отключён**. Не удаляй `~/.ssh/unissh_ed25519`.
> Ключ ставится и для `root` — как запасной вход.

## Где что лежит

| Что | Где |
|---|---|
| Конфиг серверов и настройки | `~/.config/unissh/servers.json` |
| Отпечатки хостов | `~/.config/unissh/known_hosts` |
| Бэкапы конфига | `~/.config/unissh/backups/` |
| Журнал (`0600` — в командах могут быть секреты) | `~/.config/unissh/history.jsonl` |
| Пароли | macOS Keychain или ключница Linux (`secret-tool`), сервис `unissh` |
| SSH-ключ | `~/.ssh/unissh_ed25519` |
| Экспорт ssh-конфига | `~/.ssh/unissh_config` (+ строка `Include` в `~/.ssh/config`) |

`./uninstall.sh` удалит бинарник и честно перечислит всё, что осталось.

## Как это устроено

Два пакета. `internal/core` — чистая логика: ни TUI, ни сети, ни i18n. Покрыт тестами на
**99%**, и `make build` не соберётся при покрытии ниже 90%. `internal/app` — всё, что трогает
терминал, сокет или ОС.

`make build` гейтит по цепочке `fmt` → `vet` → тесты → покрытие. `make ci` добавляет
детектор гонок. Выпустить красную сборку невозможно.

- **[ARCHITECTURE.md](ARCHITECTURE.md)** — большой технический разбор: каждое проектное
  решение, каждый компромисс и хроника наступленных граблей. Начинай отсюда, если хочешь
  понять, *почему* код выглядит именно так.
- **[SECURITY.md](SECURITY.md)** — модель угроз и известные ограничения.
- **[CONTRIBUTING.md](CONTRIBUTING.md)** — как собрать, протестировать и прислать патч.
- **[CLAUDE.md](CLAUDE.md)** — сжатая карта для AI-ассистентов.

Сделано на [bubbletea](https://github.com/charmbracelet/bubbletea),
[lipgloss](https://github.com/charmbracelet/lipgloss) и
[x/crypto/ssh](https://pkg.go.dev/golang.org/x/crypto/ssh).
Пять прямых зависимостей, без cgo.
