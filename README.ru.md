# unissh

## Возможности

- **Интерактивный главный экран** (как в lazydocker): серверы сверху, действия снизу.
  Навигация стрелками **и мышью** — клик по строке = выбор+нажатие, колесо прокручивает.
  Живой статус (онлайн/офлайн) и пинг, обновляются автоматически.
- **Авто-вход по паролю**: для серверов с парольной аутентификацией пароль вводится
  автоматически (через `expect`) — сразу готовая сессия, без ручной вставки из буфера.
  Пароль не пишется на диск и не светится в argv (передаётся через окружение).
- **Список серверов** с живым статусом (онлайн/офлайн) и пингом — Enter/клик подключает.
- **Автонастройка нового сервера** (bootstrap): обновление системы, базовые пакеты,
  sudo-пользователь со **сгенерированным паролем**, установка SSH-ключа,
  UFW/firewalld, fail2ban, харденинг sshd (вход только по ключу), смена SSH-порта,
  swap, часовой пояс, hostname, автообновления безопасности.
- **Защита от потери доступа**: вход по ключу проверяется *до* отключения паролей;
  если после изменения sshd вход не работает — конфигурация автоматически откатывается.
- **Пароли в macOS Keychain** — ничего не хранится в открытом виде.
- **Инфо-панель**: ОС, аптайм, все IP-адреса интерфейсов, загрузка CPU, load, память/диск
  с прогресс-барами, docker-контейнеры.
- **Вся инфа при добавлении**: сразу после добавления сервера unissh подключается и показывает
  полную панель — ОС, ресурсы, загрузку CPU и **все IP-адреса** со всех интерфейсов
  (v4/v6, вторичные, VPN и т.д.).
- **SSH в новом окне терминала**: по умолчанию подключение открывается в **новом окне** (Warp,
  iTerm2 или Terminal.app — определяется автоматически, пароль подставляется автоматически),
  а меню unissh остаётся под рукой. Переключается на «в этом же окне» в Настройках.
- **Live-монитор**: CPU, RAM, диск, сеть в реальном времени.
- **Команды на нескольких серверах** сразу (параллельно).
- **Экспорт в ~/.ssh/config** — `ssh <имя>` работает из любого терминала.
- Быстрое подключение: `unissh prod` прямо из шелла.
- **Два языка интерфейса** — русский и английский (Инструменты → Настройки → Язык).
- **Запоминает ваши предпочтения**: выбранные шаги настройки нового сервера становятся
  дефолтом для следующего раза (и правятся в Настройках).

## Установка

```bash
cd unissh
./install.sh
```

Требуется Go (`brew install go`). Скрипт соберёт бинарник и положит его в `~/.local/bin`.

## Использование

```
unissh              интерактивное меню
unissh <имя>        быстрое подключение (поддерживает префикс имени)
unissh list         список серверов со статусами
unissh add          добавить сервер
unissh version      версия
```

### Добавление сервера с автонастройкой

1. `unissh` → «➕ Добавить сервер»
2. Введите имя, IP, порт → «🚀 С первоначальной настройкой»
3. Укажите пароль root (обычно приходит от хостера)
4. Отметьте нужные шаги (по умолчанию включено всё безопасное)
5. Утилита всё сделает сама и покажет карточку с новым логином и паролем
   (пароль уже в Keychain и в буфере обмена)

### Что делает харденинг SSH

- вход только по ключу (`PasswordAuthentication no`)
- root — только по ключу (`PermitRootLogin prohibit-password`)
- лимиты попыток входа, keepalive-таймауты, отключение X11

⚠️ После харденинга вход по паролю невозможен — не удаляйте ключ
`~/.ssh/unissh_ed25519`. Ключ дополнительно ставится и для root (запасной доступ).

## Где что хранится

| Что | Где |
|---|---|
| Конфиг серверов | `~/.config/unissh/servers.json` |
| Отпечатки хостов | `~/.config/unissh/known_hosts` |
| Пароли | macOS Keychain (сервис `unissh`) |
| SSH-ключ | `~/.ssh/unissh_ed25519` |
| Экспорт ssh-конфига | `~/.ssh/unissh_config` |

## Удаление

```bash
./uninstall.sh
```
